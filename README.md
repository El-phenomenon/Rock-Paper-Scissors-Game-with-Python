# Rock-Paper-Scissors-Game-with-Python
A simple command-line implementation of the classic Rock, Paper, Scissors game built with Python. This version is designed for two players, allowing Player 1 and Player 2 to compete against each other.

How to Play
Player 1 enters their choice: Rock, Paper, or Scissors.
Player 2 enters their choice.
The game compares both selections and announces the winner.
If both players choose the same option, the game ends in a tie.

Game Rules
Rock beats Scissors.
Scissors beats Paper.
Paper beats Rock.
If both players make the same choice, the result is a tie.
